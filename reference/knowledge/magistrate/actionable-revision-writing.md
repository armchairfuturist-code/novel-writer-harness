# Actionable Revision Instructions

## What Makes a Revision Instruction Actionable

Bad: "The pacing is off."
Good: "Cut the 300-word description of the garden. Move the confrontation from page 4 to page 2. End the chapter on the line 'She knew then it was a trap.'"

## Rules

1. **Be specific**: name the exact sentence/paragraph/scene to change
2. **Be directive**: use imperative verbs (change, remove, add, move, rewrite)
3. **Explain the why**: briefly state what canon/beat was violated
4. **Provide the fix**: give the corrected version when possible
5. **Prioritize**: FATAL breaks before WARNINGs, continuity before prose

## Conflict Resolution

When Lore Prosecutor and Plot Sentinel conflict:
- If a lore fix would create a plot problem: flag the conflict explicitly
- If a plot fix would create a lore problem: flag the conflict explicitly
- If both agents flag the same issue: merge into one instruction
- If one agent flags FATAL and the other WARNING: FATAL takes precedence
- Eliminate subjective complaints ("I don't like the dialogue flavor")
