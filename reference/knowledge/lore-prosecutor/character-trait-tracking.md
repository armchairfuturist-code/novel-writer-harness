# Character Trait Tracking

## Common Drift Patterns

Character trait drift is the most common continuity error in long-form fiction. The LLM forgets a character's established traits and invents new ones mid-story.

**High-risk traits (check these every chapter):**
- Eye color (most commonly drifted — blue becomes brown between chapters)
- Hair color and length
- Scars, tattoos, birthmarks
- Height and build
- Age and apparent age
- Handedness (left-handed character suddenly using right hand)
- Speech patterns and accent
- Physical limitations (injuries, disabilities)

## Detection Strategy

When evaluating a chapter, cross-reference EVERY named character against their canonical traits:

1. For each character mentioned in the chapter, check ALL physical descriptors against the canonical record
2. Pay special attention to sensory descriptions (what the POV character sees)
3. If a trait was established in an early chapter and the draft contradicts it, flag as FATAL
4. If a trait is first introduced in this chapter without prior establishment, flag as WARNING only if it contradicts something implied

## Relationship Tracking

Characters don't exist in isolation:
- Relationship status changes (enemy → ally, stranger → lover) must be earned
- A character who "would never trust X" in Ch 3 shouldn't confide in X in Ch 5 without a scene showing the shift
- Characters referencing events they weren't present for = FATAL

## Inventory Tracking

Track what characters carry:
- Weapons, artifacts, keys, documents
- If a character loses an item in Ch 4, they can't use it in Ch 7
- If a character receives an item, note the transfer
