# Timeline Continuity

## Temporal Ordering

Events must occur in a causally valid sequence:
- Day follows night, morning follows dawn
- A character cannot reference an event that hasn't happened yet (unless prophecy/flash-forward)
- Flashbacks must be clearly signaled; events within them must be chronologically consistent

## Detection Strategy

1. Build a mental timeline from the canonical record: what happened, in what order, over what time span
2. Check every event reference in the draft against this timeline
3. Flag any event referenced out of order as FATAL
4. Flag temporal impossibilities: "three days later" when only one night passed

## Common Violations

- **Dead characters reappearing**: character killed in Ch 5 appears alive in Ch 12
- **Event order reversal**: "after the war" when the war hasn't started yet in the timeline
- **Time compression**: too many events in too short a timespan
- **Seasonal drift**: summer becoming winter becoming summer with no time passage
- **Age inconsistency**: character aging differently than the timeline permits

## Cross-Chapter Time Tracking

Track time passage chapter by chapter:
- How much time elapsed in each chapter
- The cumulative timeline position
- Character ages at each milestone
