# Pacing Diagnostics

## Scene-Level Pacing

Evaluate whether each scene carries its narrative weight:
- A 2000-word scene that advances nothing: pacing drag
- A 200-word scene that covers a major revelation: pacing rush
- The ratio of action to reflection should match the chapter's position in the arc

## Structural Pacing Signals

- **Front-loaded**: all action in first 30 percent, remainder is denouement: weak structure
- **Back-loaded**: 70 percent setup, 30 percent payoff: works for reveal-late chapters only
- **Sagging middle**: strong opening and closing, nothing in between
- **Breathless**: no quiet moments, constant action: reader fatigue

## Detection Strategy

1. Map scene boundaries in the draft
2. Calculate word count per scene
3. Identify each scene's narrative function (advance plot / develop character / build world / create tension)
4. Flag chapters where one function dominates disproportionately
