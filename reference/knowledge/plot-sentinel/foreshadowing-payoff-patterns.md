# Foreshadowing Payoff Patterns

## The Setup-Payoff Contract

Every foreshadowing element is a promise to the reader. Unfulfilled promises damage trust.

### State Machine
- **planted**: Element introduced as a seed
- **hinted**: Subtle reminder or second reference
- **reinforced**: Third+ signal, reader should notice
- **due**: Payoff expected in this chapter range
- **overdue**: Payoff window passed without resolution - FLAG AS MISSING
- **paid**: Seed successfully resolved

## Detection Strategy

1. Check all due/overdue threads: did this chapter address them?
2. Scan for spontaneous plants: new mysterious elements not in the tracker
3. Verify payoff quality: was the resolution satisfying or perfunctory?

## Spontaneous Planting

When the LLM introduces a new mystery without registration:
- "She noticed a strange mark on the wall" with no follow-up - FLAG
- "He pocketed the letter without reading it" with no later payoff - FLAG
- These cause compounding hallucination problems in later chapters
