# Outline Beat Compliance

## Beat Verification

Each chapter has explicit requirements from the outline:
- Key events that MUST occur
- Genre-specific required elements
- Emotional arc targets
- Character arc beats

## Detection Strategy

1. Extract the chapter's outline requirements
2. Search the draft for evidence each requirement was met
3. Missing required elements: FATAL if genre-critical, WARNING otherwise
4. Elements present but perfunctory (mentioned in one sentence): WARNING

## Genre-Specific Requirements

- **Mystery**: clues must be planted, suspects must appear on schedule
- **Thriller**: tension must escalate, stakes must rise
- **Romance**: relationship beats must hit on schedule
- **Fantasy**: world rules must be demonstrated, not just described
- **Sci-Fi**: technology rules must constrain the plot, not just decorate it
